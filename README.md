# Vertex Cover and Graph Coloring

COSC 520 – Assignment 3 (UBC Okanagan, Fall 2026)

Repository: https://github.com/smahdieh/graph-algorithms

Compares two approximation algorithms for each of two NP-hard graph
problems, all implemented from scratch (no graph-algorithm libraries), and
benchmarks them on the BHOSLIB/FRB graphs and on random graphs.

| Problem | Algorithm A | Algorithm B |
|---|---|---|
| Vertex cover | Basic: add **both** endpoints of an uncovered edge (2-approximation) | Randomized: add **one** endpoint, chosen at random |
| Graph coloring | Greedy in arbitrary order (0, 1, …, n−1) | Greedy in **smallest-last** order (Matula & Beck) |

All four run in O(V + E) time and O(V) extra space.

## Quick start

```bash
pytest                           # 115 unit tests, under 1 s
python data/download_dataset.py  # FRB dataset, about 6 MB download
python demo.py                   # demo, about 2 s
```

The demo runs all four algorithms on small graphs with known answers (star,
complete graph, odd cycle, tree, crown graph), on one FRB graph with a known
optimal cover, and on a random graph with 100,000 vertices. It works without
the dataset too (the FRB part is then skipped).

## Usage in code

```python
import sys; sys.path.insert(0, "src")
from graph_algorithms.graph import Graph, load_dimacs
from graph_algorithms.vertex_cover import basic_vertex_cover, randomized_vertex_cover
from graph_algorithms.coloring import greedy_coloring, smallest_last_coloring, num_colors

graph = Graph.from_edges(4, [(0, 1), (1, 2), (2, 3), (3, 0)])   # or load_dimacs("data/frb/frb30-15-1.mis")
basic_vertex_cover(graph)                  # {0, 1, 2, 3}
randomized_vertex_cover(graph, seed=1)     # a smaller cover, same every time for seed=1
num_colors(greedy_coloring(graph))         # 2
num_colors(smallest_last_coloring(graph))  # 2
```

## Dataset

**BHOSLIB / FRB benchmark** (Ke Xu), MIS format:
https://rb-bench.github.io/benchmarks/hidden-opt-graph.html

`python data/download_dataset.py` downloads the 8 families frb30-15 …
frb59-26 (5 instances each, 40 graphs, 450–1534 vertices, 18k–127k edges)
into `data/frb/`. An frbN-K graph has N·K vertices and a hidden independent
set of size N, so its **minimum vertex cover has size N·K − N**, which lets
us measure how far each cover is from optimal. You can also download only
some families, e.g. `python data/download_dataset.py 30-15 40-19`.

The random graphs (1,000 to 128,000 vertices, average degree 10) are
generated by the benchmark script with fixed seeds, so they need no download.

## Reproducing the results

```bash
python benchmarks/run_benchmarks.py           # full run, a few minutes
python benchmarks/plot_results.py             # figures + summary table
```

- `run_benchmarks.py` runs every algorithm on every graph, checks each
  output is a valid cover / proper coloring, and records the median time of
  5 runs (10 seeds for the randomized cover), peak extra memory
  (`tracemalloc`, in a separate run), and the cover size or number of
  colors. It writes `results/results.csv`, `results/environment.json` and
  prints a log (saved in `results/log_benchmark.txt`).
  `--quick` does a small run in about a second.
- `plot_results.py` writes `runtime`, `memory`, `cover` and `colors`
  (`.pdf` and `.png`) and `summary_table.tex/.csv` to `results/figures/`.
  The figures are typeset with LaTeX in the ACM template's fonts; add
  `--no-latex` if LaTeX is not installed, and `--copy-to <dir>` to copy the
  PDFs into a report folder.

## Results at a glance

| | |
|---|---|
| Runtime | all four grow linearly in V + E; smallest-last is 3–6× slower than plain greedy (building the order) |
| Vertex cover (FRB) | basic 1.039–1.069 × optimum, randomized 1.037–1.065 × optimum |
| Vertex cover (random) | randomized about 7% smaller than basic |
| Coloring | smallest-last uses fewer colors on every family, e.g. 46.4 vs 57.2 on frb59-26 |

Full numbers: `results/figures/summary_table.csv`.
