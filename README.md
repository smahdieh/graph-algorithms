# Vertex Cover and Graph Coloring

COSC 520 – Assignment 3 (UBC Okanagan, Fall 2026)

Compares two approximation algorithms for each of two NP-hard problems,
all implemented from scratch (no graph-algorithm libraries):

| Problem | Algorithm A | Algorithm B |
|---|---|---|
| Vertex cover | Basic (add both endpoints) | Randomized (add one endpoint) |
| Graph coloring | Greedy, arbitrary order | Greedy, chosen node ordering |
